# 오류 알림

모델 가져오기, 저장소와 계정 등 기존 알림 기록에 추가된 오류를 현재 콘텐츠 영역 우측 상단의 LVUI 팝오버에 순서대로 표시한다. 전역 도구모음을 가리지 않으며 콘텐츠 영역의 이동·크기 변경과 좁은 창에 따라 배치와 너비를 갱신한다. 시작 화면이 보이면 해당 화면의 콘텐츠 영역으로 알림을 옮긴다. 오류 본문은 줄바꿈한 실제 콘텐츠 높이에 맞추고, 영역보다 긴 내용은 본문 안에서 스크롤한다. 팝오버 외부의 투명 호스트는 아래 콘텐츠의 입력을 가로채지 않는다. 닫기는 현재 표시만 제거하고 다음 오류를 표시하며 알림 센터의 오류 기록을 삭제하지 않는다. 진행 또는 성공 상태는 오류 알림으로 분류하지 않는다.

네이티브 Workspace의 파일 작업 오류도 기존 알림 센터에 전달한다. 기존 알림 센터가 같은 원본의 활성 오류를 중복 제거하는 경우 동일 항목이 다시 추가되지 않는다. 별도 Society Files 창에서는 파일 작업과 백엔드의 명시적인 오류를 그 창의 우측 상단에 표시하며, 같은 오류가 반복되어도 발생 순서대로 보존한다. 파일 창의 알림을 닫아도 오류 기록은 지워지지 않는다. 아직 알림에 연결되지 않은 다른 네이티브 오류와 창이 생기기 전의 치명적인 오류는 해당 경로의 기존 표시에 남는다.

기존 Qt 호스트의 이미지 렌더러는 iiGUI 그림자를 크기와 배율에 맞춰 소프트웨어로 그린다. 배경 블러는 이 호스트에서 지원하지 않아 LVUI 팝오버의 불투명 표면 폴백을 사용한다. 이 경로의 재질은 배경 캡처와 블러, 마스크 또는 별도 장면이 없는 경우에만 그리며 그 밖의 재질은 지원하지 않는다고 반환한다.

Society Figma의 `1281:9351` 알림은 같은 콘텐츠 영역 배치와 본문 줄바꿈 동작을 설명한다. `SocietyNativeWorkspaceSurfaceTests`는 콘텐츠 영역과 시작 화면 전환, 이동·크기 변경, 여러 줄 메시지의 패널 포함, 긴 본문의 스크롤, 투명 영역의 입력 통과와 오류 기록 보존을 창을 화면에 띄우지 않는 구성에서 검증한다. 이 검사는 실제 운영체제 창에서의 표시를 대신하지 않는다.
