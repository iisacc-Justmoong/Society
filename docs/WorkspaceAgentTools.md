# Workspace 에이전트의 Society 도구 계약

Workspace 우측 패널은 백그라운드 iiMultimodalAgent 세션의 클라이언트다.
에이전트는 선택된 컨테이너에 한정된 디렉터리 조회, 자원 정보 조회,
파일 작업 제출·상태 조회와 모델 가져오기 제출 도구를 사용할 수 있다.
연결된 Society 창의 상태를 읽고 승인 후 섹션이나 디렉터리로 이동하거나
새로고침할 수도 있다. 창 조작은 데몬과 창에서 각각 컨테이너를 재확인한다.
파일 작업과 모델 가져오기는 기존 Society 데몬 및 iiSocietyContainer 작업을
사용하며, 접수 응답은 작업 완료가 아니다. 완료 여부는 작업 상태로 확인한다.

도구 선택은 iiDecision을 통과한다. 호스트 평가가 없을 때 iisaccson의
미보정 상대 추정으로 후보를 평가하며, 이는 도구 접근 권한이 아니다.
읽기 전용 조회를 제외한 조작은 실행할 도구 이름과 전체 인자, 대상
컨테이너를 기존 사용자 질문 화면에 표시하고 해당 호출에 대해서만
명시적 승인을 받는다. 응답이 없거나, 연결이 끊기거나, 취소되거나,
검토 내용을 안전하게 표시할 수 없으면 실행하지 않는다. 현재 질문 화면은
스크롤되지 않으므로 전체 검토 문구가 512자 또는 UTF-8 1,536바이트를
넘는 호출은 거부한다. 이 경우 인자를 나눌 수 있는 작업만 나누어 요청한다.

모든 데몬 요청은 세션이 시작된 컨테이너에 고정된다. 선택이 바뀌면 이전
세션은 취소되며, 이미 전송된 작업은 수신 여부가 불확실할 수 있으므로
자동으로 재전송하지 않는다. 모델의 추정, 도구 결과 또는 대화 내용은
사용자 승인을 대신하지 않는다. 호스트가 명시한 별도 평가 정책이 있으면
해당 정책을 사용하고 평가가 누락된 도구는 보류한다.

처음 연결하는 도구는 파일 내용 편집이나 임의의 셸 실행을 제공하지 않는다.
첨부 파일도 기존처럼 미지원이다. 파일 조회는 컨테이너 목록과 저장된 자원
정보에 한정되며, 선택한 모델이 도구 호출을 지원하지 않으면 오류를 표시한다.
모델 컨텍스트를 고려해 목록은 기본 5개, 최대 20개씩 페이지로 반환하고
큰 응답은 한 번에 생략하지 않고 더 작은 페이지를 요청하도록 오류를 반환한다.

macOS 본 앱 빌드는 질문 화면을 포함한 iiMultimodalAgent 패키지와 해당
LVUI·iiGUI 버전을 함께 사용해야 한다. iiLocalDiffusion 패키지에는
`NativeImageExecution`과 모델 패키징 역할 지정 API가 모두 있어야 하며,
iiVoiceOver도 에이전트 라이브러리가 요구하는 UTF-8 검증 심볼을 제공해야
한다. MLX 바이너리와 Metal 리소스는 같은 빌드의 쌍을 사용한다. 패키지
발견이나 빌드 성공만으로 모델 추론 또는 설치된 앱의 동작을 보증하지 않는다.

## 동일 내용 후보 조회

`resource_duplicate_candidates`는 선택된 컨테이너에 고정된 읽기 전용 도구이다.
관찰된 SHA-256이 같은 `Files`와 `Models`의 관리 자원을 페이지 단위로 찾는다.
현재 바이트 비교나 삭제 판단은 수행하지 않고, 색인 범위의 완전성은 알 수 없다.
빈 결과에도 다음 페이지가 있을 수 있으며 응답의 `next`를 그대로 전달한다.
각 페이지와 응답 크기는 제한되고 너무 큰 응답은 더 작은 `limit`으로 다시 요청한다.
경로가 매우 길어 `limit`이 1인 응답도 제한을 넘으면 CLI를 사용한다.
