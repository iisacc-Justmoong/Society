# 계정이 소유하는 라이선스 관리와 앱 실행 허가

Society는 `AccountSession`의 iiAccountManager를 보유한다. iiAccountManager가
`unique_ptr<LicenseManager>`로 iiLicenseManager의 구현과 상태를 내부 소유한다.
두 SDK를 나란히 링크하거나 외부 라이선스 관리자를 계정에 주입하지 않는다.
Society의 빌드·실행 의존성에는 별도 iiLicenseManager 모듈이 없다.

`ensureLicenses()`는 보안 저장소의 계정·기기별 토큰을 먼저 확인한다.
서명·발급자·대상·계정·기기·제품·만료가 유효하면 네트워크 없이 허용한다.
토큰이 없거나 사용할 수 없을 때 인증된 `accountLicenses` 요청으로 갱신한다.
화면 진입과 앱 허가 요청은 이 경로를 사용한다. 사용자의 Refresh는 서버 결과로
기존 상태를 교체한다. 정상적인 미보유 응답도 서명되며 이전 허가를 덮어쓴다.

서버 서명 토큰의 기본 수명은 24시간이다. 세션과 제품 만료가 상한이다.
로그아웃 시 계정 내부 상태와 보안 저장소 토큰을 삭제한다. 오프라인 상태의
원격 폐기는 다음 명시 갱신 또는 만료 때 반영된다.

주 앱은 시작 및 로그인 복구 시 로컬 우선 경로를 준비한다.
`127.0.0.1:49627/v1/authorize`에서 다른 앱의 실행 허가를 처리한다.
Congregation·Dreamscapes·Vincent의 등록 제품/앱 조합만 받으며 요청 계정과
기기가 Society와 같아야 한다. 응답은 요청 ID, 허가, 서명 토큰, 만료를 포함한다.
브라우저 Origin, 잘못된 Host, 과대 요청, 중복 길이·전송 헤더는 거부한다.
외부 네트워크에 수신하지 않으며 계정 쿠키와 온라인 세션 토큰을 반환하지 않는다.
소비 앱도 서명을 검증해야 한다. 로컬의 임의 응답은 허가 근거가 아니다.

Environment → Apps에는 검증된 라이선스 보유 여부와 연결된 앱/브라우저를 표시한다.
제품은 설치 여부와 라이선스 상태를 구분하며, 현재 세션을 임의 해제하지 않는다.
연결 해제는 계정 서버의 공통 레지스트리를 사용한다.

`SocietyAccountTests::societyMountsAccountLicenseInventory`는 내부 관리자 소유,
로컬 토큰 재사용 시 서버 요청 0건, 실제 HTTP 허가, 다른 기기 및 브라우저 요청
거부, 미보유·위조 주체·로그아웃과 연결 해제를 검사한다. 다른 플랫폼의 소스
이식과 해당 플랫폼에서 두 앱을 연결한 실제 실행 검증은 구분한다.

소비 앱은 Society가 승인한 서명 토큰을 자체 계정 SDK 안에 안전하게 보관할 수 있다. Society가 중지·종료되어도 토큰 만료까지 위임이 유효하며, 다시 연결되어 명시 거부를 받으면 위임을 삭제한다. iPadOS의 백그라운드 중지는 이 정책으로 처리한다.

## 통합 검사 준비 조건

계정 통합 검사에서 전송 연결과 호스트 서비스 준비를 구분한다. 원격 생성 RPC는
네임스페이스 바인딩이 완료된 뒤 전송한다. 파일 잠금 충돌은 SDK가 같은 요청
안에서 재시도하므로 연결 검사도 즉시 오류 문구를 기대하지 않고 인증 유지와
잠금 해제 후 완료를 확인한다. 파일 실체화는 최대 30초, 별도 NAS 프로세스의 최초 바인딩은 최대 60초로 한정하며, 여러 실제 동기화 시나리오를 포함하는 전체 검사 실행 제한은 180~240초로 설정한다.
